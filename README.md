# Tetris Mobile

Ein kleines Tetris-Spiel als mobile Web-App (PWA).

## Features

- Touch-Steuerung mit großen Buttons
- Tastatur-Support (Pfeile, Leertaste, `P`)
- Score, Level und Linien
- Start, Pause und Reset
- Offline-Caching per Service Worker

## Lokal starten

```bash
python3 -m http.server 4173
```

Dann im Browser öffnen: `http://localhost:4173`
